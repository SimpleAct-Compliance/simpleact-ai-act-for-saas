# Vorlage: Funktionsregister

Ein Eintrag **je KI-Funktion im Produkt**, nicht je Produkt. Für intern eingesetzte KI gilt ein eigenes Register — dort sind Sie Betreiber, nicht Anbieter.

Leerfelder sind kein Ergebnis. Was nicht bekannt ist, bekommt **nicht bewertet** plus Person und Termin.

## Mehrmandanz

| Feld | Eintrag |
|---|---|
| Geteilte Modellinstanz? | ja / nein |
| Mandantenspezifische Konfiguration möglich? | keine / Vorlagenauswahl / Textbausteine / **freie Eingabeaufforderung** |
| Mandantenspezifische Feinabstimmung? | ja / nein |
| Fließen Daten eines Mandanten in Ausgaben für andere? | ja / nein |
| Wie wird die Trennung **technisch erzwungen**? | |
| Technisch erzwungene Grenzen der Konfiguration | |

Freie Konfiguration bedeutet, dass der Mandant mitbestimmt, was das System tut. Die vorletzte Zeile ist dann der eigentliche Schutz: Was technisch nicht möglich ist, muss nicht vertraglich verboten werden.
